# Zyrro Identity Report Blueprint v1

## Core Report Objective

Produce a high-accuracy identity mirror that makes the user feel one thing immediately:

**“This is me.”**

Not inspiration.
Not advice.
Not coaching.

Recognition.

The report should feel like precise pattern recognition — as if the user is seeing their operating system clearly for the first time.

This is the **Registered** tier's deliverable: the **Identity Signature Report** (descriptive only).

Its job is to create trust, certainty, and self-recognition.

---

# Global Output Standards

## Tone Rules

Must be:

- precise  
- intelligent  
- grounded  
- emotionally accurate  
- direct  
- calm  
- honest

Must NOT be:

- motivational  
- fluffy  
- generic  
- vague  
- mystical  
- therapeutic

---

## Writing Rules

Every major observation must be grounded in user evidence.

No unsupported claims.

Every major identity claim must connect to:

- a career chapter  
- a turning point  
- a frustration pattern  
- an energising moment  
- an achievement  
- a repeated life pattern

---

## Tense Rules

Use **present tense** for identity.

Example:

“You build systems.”

Use **past tense** for evidence.

Example:

“You rebuilt your practice after your co-founder left.”

---

# Final Test

Before outputting, ask:

Does this report create the reaction:

**“This is me.”**

If not:

It is not ready.

Recognition is the product.
