## 2026-08-25 — Reframe teaser redesign: /identity CTA section + retire identity_reframe

Per `docs/briefs/reframe-teaser-redesign-brief.md` (supersedes #116,
folds in #114, retires #98/#113's `identity_reframe` architecture).
Schema + prompt change (`ReframeTeaser`: drop `why_bullets`, add
`forward_frame`), a new shared component, and both `/identity` and
`/path` rewired to render it identically. `lib/prompts/path-options.ts`
and physical deletion of `identity_reframe` code/migration left alone,
exactly as scoped out.

### Changed

`lib/artifact-schemas.ts` — `ReframeTeaser`: dropped `why_bullets:
string[]`, added `forward_frame: string`. No nesting change, no backfill
(same precedent as `domain_profile_summary`).

`lib/prompts/identity-report.ts` (`LAYER_2_PROMPT`) — removed the
`why_bullets` instruction block and its mentions in the pre-return
checklist and structural constraints; added a `forward_frame` block:
question-framed register, sourced primarily from Q10–13 (avoidance,
what still energises despite frustration, last-felt-confident moment,
wanted change), hard rules against quoting/restating raw answers and
against naming a destination/role/outcome, a required stakes beat +
Path Options value-bridge, minimum 55/target 70 words. `lib/layer2-minimal-pilot.ts`
and `lib/call2-pilot.ts` both carry their own copies of this instruction
block but are confirmed standalone pilot files (their own doc comments
say so — not wired into `generateIdentityReport` or any route) — left
untouched.

`lib/generate-identity-report.ts` — `logReframeTeaserWordCountGaps`:
dropped the `why_bullets` loop and `REFRAME_TEASER_BULLET_MIN_WORDS`,
added a `forward_frame` check against new
`REFRAME_TEASER_FORWARD_FRAME_MIN_WORDS = 55`. Same log-only pattern,
no behavior change otherwise.

New `components/ReframeCtaBlock.tsx` — the shared 6-part composition
(headline, recap, pullquote, forward_frame, static "what you get"
bullets, price + CTA), used identically by both pages instead of
copy-pasted JSX, so the two pages' output is identical by construction.
Bullet 1 interpolates a deterministic signature-name callback (e.g.
"your Pioneer/Activator constellation") from `primary_constellation[0]`/`[1]`
rather than relying on the LLM to get it right.

`app/identity/page.tsx` — local `reframe_teaser` type now imports
`ReframeTeaser` from `lib/artifact-schemas` instead of a hand-inlined
shape; added `checkoutLoading` state + `handleCheckout` (same shape as
`/path`'s existing one); `.cta-block` JSX replaced with
`<ReframeCtaBlock>`, guard updated to check `forward_frame` instead of
`Array.isArray(why_bullets)`.

`app/path/page.tsx` — removed entirely: `reframeArtifactId`,
`reframeStartFailed`, `reframeGenPhase`, `reframeContent`,
`loadOrStartReframe`, `handleRetryReframe`, the
`IdentityReframeArtifactContent` import, and all four
idle/spinner/come-back-later/failed polling render branches. The
existing `identity_report` fetch in `init()` now also captures
`reframe_teaser` and `primary_constellation` into state (no second
fetch). Unpaid branch renders the same `<ReframeCtaBlock>` as
`/identity`. Also removed the dead `namedIdentity` state (confirmed via
grep it was read nowhere once the old headline JSX was gone) and the
`NEXT_PUBLIC_PRICE_DISPLAY` conditional price pill — confirmed via git
history (`git log -S`) it was untouched, undocumented scaffolding from
the original Jun 1 Phase-1 commit, never set in any env this repo has
visibility into, before dropping it in favor of the brief's static "$49,
one-time." text.

`app/globals.css` — removed `.reframe-bullets` (list/li/::before rules),
now-orphaned since the `why_bullets` render it supported is gone;
confirmed via full-repo grep it had no other call site (same check
#115 used before deleting `.chip-friction`/`.chip-energiser`).
`.reframe-pullquote` kept as-is, still used.

`npx tsc --noEmit` — clean throughout.
