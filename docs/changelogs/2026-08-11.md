### Stage 0 — Evidence data audit

**Premise correction (the actual headline finding of this stage).** The
brief's data source — "`evidence_units` and `signatures[]` already
persisted on `identity_report` artifacts since #62 shipped" — is only
half true. Queried live Supabase directly (23 `identity_report` artifacts,
8 with `raw_signature_analysis` present, all from 2026-08-04 onward):

```

Of those, raw_signature_analysis containing an 'evidence_units' key: 0
Of those, raw_signature_analysis.signatures non-empty array: 8

  'signatures', 'emerging_signatures', 'secondary_signatures',
  'primary_constellation', 'suppressed_signatures'

```

`evidence_units` was never actually persisted — `#62`'s scope, as
actually shipped in `lib/generate-identity-report.ts:590-596` and typed in
`lib/artifact-schemas.ts:176-182`, only ever wrote the full `signatures[]`
array plus the four categorization lists (`primary_constellation`,
`secondary_signatures`, `emerging_signatures`, `suppressed_signatures`).
Layer 1 generates `evidence_units` transiently every run but it's
discarded before the `artifacts.content` write — it never reaches the DB.
Confirmed no separate artifact type carries it either: the only `type`
values present in the live `artifacts` table are `identity_reframe`,
`identity_report`, `path_options`, `path_plan` — no `signature_analysis`
type (the `SignatureAnalysisArtifactContent` type in

**Practical effect:** measures 1, 2, and 4 (all keyed on `evidence_units`

not a weak signal, a hard zero across every real report generated to
date. Per Miroslav's direction, these were folded into Stage 1's
verification pass instead (see below) rather than dropped, since Stage 1
generates fresh `evidence_units` against the same real users' real
`discovery_answers` anyway.

**Measure 3 — evidence density per signature by `score_band`.** This one
*is* answerable — `signatures[].evidence_count` is real, persisted data,
independent of the missing `evidence_units` array. All 8 artifacts, 43

Clean, monotonic, low-noise relationship (`weak` has *zero* variance — every

cite, confirmed by real data, not inferred.
