## 2026-10-04 — #154 step 1: Identity Report generated content (Layer 3)

Executed `docs/briefs/154-step1-identity-report-content.md` (#154, step 1 of 4). Implementation

### Changed

- **Layer 3** (`lib/generate-identity-report.ts`, new prompt `lib/prompts/identity-report-deep-dive.ts`):
  a separate step after Layer 2 that generates the new fields (schema `1.4`, all optional):
  `signature_deep_dives`, `pairings`, `distinctive_pattern`, `pattern_to_notice`.
  - Calls: one deep-dive call per signature that has at least one tagged evidence unit, then one
    report-level call that builds `pairings` from the deep dives' `works_with`.
  - Rate limits: concurrency 3, 429 backoff that honours `retry-after`, up to 8 retries.
  - Failures: calls fail independently. A failed deep dive drops only that signature; a failed
    report-level call drops only its three fields. With no `works_with` data, `pairings` is left
    out. The Layer 2 report is never lost.
  - Evidence rules (#92 handling): units are counted through either candidate field. A signature
    with 0 units gets no deep dive; one with 1 unit gets a reduced deep dive. Both are enforced in
    code. Evidence is capped at the unit count and never borrowed from another signature.
  - Log-only backstops: evidence and `works_with` sources, word and item counts, the signature's
    own name inside `what_this_means`, signature names in Distinctive Pattern, overlap with main
    report text, and trailing interpretive clauses in evidence lines.
- **Layer 2 prompt:**
  - Shared rule text now lives in `lib/prompts/shared-report-rules.ts` and Layer 3 reuses it
    verbatim. That covers Voice, Evidence Reuse, Writing Principle, Specificity, No Coaching, No
    Generic Praise, tense, and a new British English rule (closes #97).
  - No longer generates `domain_profile_summary`, `what_this_report_is` or
    `cover.identity_context`. They stay optional in the type so old reports still parse.
  - Energisers and friction points must be phrases of minimum 3 words, target 4, maximum 6.
    A log-only backstop flags items outside that range.
- **/path:**
  - `identity_context` is removed from Path report generation, storage and the cover line. Old
    Path reports that still store it render without it.
  - `generate-path-plan` strips the Layer 3 fields from its prompt input via `omitLayer3Fields`.
- **/identity:** the cover line is guarded, so 1.4 reports don't end in a dangling " · ".
  Pre-1.4 reports render unchanged.
- **`lib/llm.ts`:** new `getChatCompletionDetailed`, which returns token usage including cached
  tokens. Only Layer 3 uses it; no other call site changed.

### Verification (throwaway scratchpad scripts, none committed)

- **Investigation:**
  - Timing probe on real users: a single combined Layer 3 call dropped signatures (5/8 and 3/5),
    while per-signature calls stayed complete.
  - The org's gpt-4o limit is 30k tokens per minute, so parallel calls hit 429s.
- **Layer 2 baseline:** HEAD prompt vs new prompt on the same Detection output. The new prompt was
  +6.7% (`evidence_analysis`) and +7.8% (`how_you_operate`), so the short Layer 2 fields predate
  this change.
- **Generation runs** on real users (e9ead1ad, 142b7b50, 9afc7420, 041dd262): 33–94s per user
  against the 240s `maxDuration`.
- **Offline tests** of the orchestration with mocked `fetch`: 0-unit signature, 1-unit reduced
  mode, a failed deep dive, a failed report-level call, and no `works_with` data. All pass.
- **Live /path regression** via `scripts/run-verification.mts` with a newly generated 1.4 report:
  - Direction accepted the new energiser and friction-point strings.
  - Options generated, and the Path report generated with no identity context line.
  - A pre-#154 Path report rendered without the line.
  - A pre-1.4 identity report rendered unchanged on `/identity`, cover line included.
- `npx tsc --noEmit` and `npx next build` both pass.

### Decisions

- **Layer 3 as one call per signature plus a report-level call:** the single-call variant dropped
  signatures.
- **Stay within the 30k tokens-per-minute limit for now** (concurrency 3, retries in Layer 3
  only): the tier upgrade and pipeline-wide 429 handling are logged as #155.
- **Calls fail independently:** losing one deep dive shouldn't cost the whole Layer 3.
- **The floor-check field mismatch in `enforceSecondaryEvidenceFloor` belongs to #92:** that check
  looks only at `secondary_signature_candidate`. Not fixed in #154.
- **Interpretive clauses in evidence lines accepted for this step:** caught by a log-only
  backstop, no prompt change.
- **Remaining 2-word friction points accepted for step 1:** no retry, no further tuning. Miroslav
  stated explicitly that this is **not** a Definition of Done sign-off.
- **`lib/layer2-*-pilot.ts` and `lib/call2-pilot.ts` left untouched.**
