### Changed

- **Layer 3** (`lib/generate-identity-report.ts`, new prompt `lib/prompts/identity-report-deep-dive.ts`):
  a separate step after Layer 2 that generates the new fields (schema `1.4`, all optional):
  `signature_deep_dives`, `pairings`, `distinctive_pattern`, `pattern_to_notice`.

## 2026-10-04 (late) — #155 OpenAI retry layer (code part)

### Changed

- **`lib/llm.ts` is the single retry layer for every OpenAI call.**
  - The SDK's own retries are off, so nothing retries twice.
  - 429: up to 8 retries, honouring retry-after, else backoff capped at 20s per wait.
  - `insufficient_quota` fails immediately.
  - 408 / 409 / 5xx / connection errors: up to 2 retries.
  - Every call has a total waiting budget (default 60s) and an optional deadline it never sleeps
    past. One log line per retry.
- **Pipeline deadline (start + 220s)** shared by all calls in identity generation, path options,
  path report and the checkpoint stages (`withPipelineDeadline`). Layer 3's own 429 loop is
  removed.
- **Mentor:** 2 retries, 10s total wait, retry-after honoured only if ≤ 5s. Still rate-limited
  after that returns a 503: "Mentor is busy, try again in a moment".
- **`maxDuration` set:** mentor 60, project name 60, end-conversation 60, meta bundle 120 (one
  shared 110s deadline). Project name and conversation bundle get a 20s retry budget.
- **Verified:**
  - Mocked-fetch test of every retry case.
  - Full identity report on 48ca28e9: 77.7s, 5 rate-limit retries, all calls succeeded.
  - Live mentor message for a synthetic user: 200 in 3.1s.

### Decisions

- **Mentor `maxDuration` is 60, not 30:** mentor has no `max_tokens`, so a long reply needs the
  headroom. No `max_tokens` was added.
