Brief: `docs/briefs/brief-bundle-slim.md` (deleted this session — see Next).

### Changed

- **First pass** (commit `8d4307d`): rewrote `scripts/make-bundle.mjs` from "every tracked text
  file" to a curated default (AGENTS.md, non-changelog docs, `utils/supabase/`, and the `lib/` files
  shared by both the `/path` and `/identity` flows) plus two opt-in area presets (`path`, `identity`)

  `from '...'` imports outward from each flow's entry points (`app/path/page.tsx`;

  `components/SignupModal.tsx`) that were flagged rather than silently classified. Also added:
  changelog trimming (3 most recent), migration-filenames-only + extracted `artifacts_type_check`
  values, a trimmed file tree, `--include <path>`, a `400KB` warning, the `npm run bundle` script,
  and a `bundle` / `bundle path` / `bundle identity` session command in `AGENTS.md`.
- **Reverted** (commit `23193a6`, this same session, on direct instruction): went back to the
  original "every tracked text file" approach (`git checkout 656062d -- scripts/make-bundle.mjs`),
  keeping only the zip-output addition and the plain `npm run bundle` script/command. Presets,
  changelog/migration trimming, `--include`, the 400KB warning, and the preset-aware `AGENTS.md`
  `bundle` section text are all gone again.
- **Kept across both passes**: `.zip` output. `make-bundle.mjs` now writes `context-bundle.zip`
  alongside `context-bundle.md` — a hand-rolled single-entry ZIP (CRC-32 + `node:zlib`
  `deflateRawSync`, manual local/central-directory/EOCD records) with no external tool or added
  dependency, so it works the same on Windows as anywhere else. `package.json` gained
  `"bundle": "node scripts/make-bundle.mjs"`; `.gitignore` gained `/context-bundle.zip`.
  `AGENTS.md`'s `bundle` command now just runs `npm run bundle` and reports the `.zip` path/size
  (the file to attach to the planning chat, not the `.md`).

  instead. The preset file lists and import-graph tracing aren't preserved anywhere outside git
  history (commit `8d4307d`) — if presets come back later, re-derive the lists rather than trusting
