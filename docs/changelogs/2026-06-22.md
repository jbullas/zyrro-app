## Decisions

- **Branch confirmed unreachable before deletion.** The only caller (`app/start/page.tsx`)
  always calls `supabase.auth.signUp()` immediately before posting to the route, so
  `user_id` is always a brand-new UUID with no prior artifacts. If sign-up fails the
  function returns early and the route is never called.
- **No constraint added this session** — deferred to a separate task. The correct form
  is a partial unique index scoped to `identity_report` only:
  `UNIQUE(user_id) WHERE type = 'identity_report'`. A full `UNIQUE(user_id, type)` would
  break `path_plan` / `path_options` rows where users legitimately have multiple artifacts
  of the same type.
