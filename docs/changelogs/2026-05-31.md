# Changelog — 2026-05-31 (continued)

### AI Pipeline
- Created app/api/generate-report/route.ts:
  - Accepts POST with { user_id, name, answers }
  - Uses Supabase service role key to bypass RLS
  - Inserts into profiles table (user_id, name)
  - Inserts all discovery answers into 
    discovery_answers table server-side
  - Creates artifact row immediately with 
    status: generating
  - Returns 200 immediately (non-blocking)
  - Fires generation async in background:
    Step A: identity-analysis.ts + GPT-4o,
    max_tokens 4000
    Step B: identity-report.ts + GPT-4o,
    max_tokens 8000
    Step C: updates artifact status to ready
    and writes full report JSON to content
  - On any error: sets artifact status to failed
  - Logs environment variable presence on startup

### Registration flow update
- Replaced signInWithOtp with signUp in 
  app/start/page.tsx:
  - Creates user immediately with random 
    password and display_name in metadata
  - Sends confirmation email via Supabase
  - Calls /api/generate-report immediately 
    after signUp with user_id, name, and answers
  - Pipeline fires non-blocking — user sees 
    check-email screen without waiting
  - Empty answers: skips pipeline call, 
    still advances to check-email
  - signUp failure: shows inline error
