### Decisions

- **One set of tables, filtered by `kind`:** one chat engine. Path stays out of Mentor's list,
  the dashboard and end-conversation.
- **The server owns Path conversations:** budgets, one per purchase and the profile can only be
  enforced that way.
- **Code, not the model, owns statuses and the choices it can map exactly:** in live runs the
  model invented user reasons, filled unasked items, copied stale statuses (loops) and took
  working hours as hours available.
- **Two calls per answer (step 3b):** a single call produced form-filling replies.
- **Call B on gpt-6.1-sol (Miroslav):** it passed where gpt-4o didn't, and cost about 11% less.
- **Mentor reading `path_choice`:** owned by a separate logged ticket, not #168.

### Findings

- **Full-repo `npm run lint` fails with 16 errors in files #168 didn't touch.** They're
  pre-existing. The #168 files lint clean, and the build passes.
- **`auth.signOut()` defaults to global scope.** In a script it revokes the test user's stored
  browser sessions.
- **Run 6 had no per-call usage.** That's why the usage log line was added.
- **gpt-4o got 0 cache hits on call B.** It did get them on call A. Not investigated.
