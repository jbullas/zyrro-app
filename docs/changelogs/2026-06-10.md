## Decisions

- **Persistence is write-only**: conversation resume-on-reload deferred to its own task (history is already saved).
- **Mentor route uses server-derived auth**: it loads the user's full profile — trusting a client-supplied id would let anyone read another user's data.
- **Chat model env-driven, gpt-4o default.** Grounding distilled, not full report JSON.
